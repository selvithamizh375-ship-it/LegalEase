LegalEase - VS Code C++ Project
================================

Files
-----
main.cpp   C++ source code for the LegalEase document generator.

Requirements
------------
- Visual Studio Code
- A C++ compiler such as g++ (MinGW-w64 on Windows, or g++ on Linux/macOS)

How to open
-----------
1. Extract the ZIP file.
2. In VS Code, select File > Open Folder and open LegalEase_VSCode_Project.
3. Open main.cpp.
4. Open Terminal > New Terminal.

Compile
-------
g++ main.cpp -o LegalEase

Run on Windows
--------------
.\LegalEase.exe

Run on Linux/macOS
------------------
./LegalEase

Using the program
-----------------
1. Choose a document type from the menu.
2. Enter your name and the recipient's name.
3. Enter the matter details. Type END on a new line when finished.
4. The program saves a .txt draft in the current working directory.

Important
---------
This is a template-based C++ prototype, not a real AI system. AI generation requires a secure backend and an AI API. Legal documents should be reviewed by a qualified legal professional before use.
